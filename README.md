# META-NAVI — iPhone PWA

## Что внутри
- `index.html` — интерфейс и логика приложения.
- `manifest.webmanifest` — настройки установки как PWA.
- `sw.js` — Service Worker и базовый офлайн-кэш.
- `icons/` — иконки приложения.

## Как открыть на iPhone
PWA нужно разместить на HTTPS-хостинге. Открытие `index.html` как локального файла не даст установить приложение на экран «Домой».

### Самый простой вариант: GitHub Pages
1. Создай репозиторий на GitHub.
2. Загрузи в корень репозитория все файлы и папку `icons`.
3. В Settings → Pages выбери публикацию из ветки `main`, папка `/root`.
4. Дождись появления HTTPS-ссылки.
5. Открой эту ссылку именно в Safari на iPhone.
6. Нажми «Поделиться» → «На экран Домой» (Add to Home Screen).
7. Если появится переключатель «Открывать как веб-приложение» / Open as Web App — включи его, затем нажми «Добавить».

После установки запускай META-NAVI с иконки на домашнем экране. При первом открытии дай странице загрузиться с интернетом, чтобы Service Worker сохранил файлы для офлайн-запуска.

## Важно
Это стилизованный персональный интерфейс/симуляция. Он не подключается к настоящему Metaverse и не определяет реальные координаты «дворцов». Данные заметок и Persona-архива хранятся локально в браузерном хранилище этого устройства. Очистка данных сайта может удалить их.

iOS PWA имеет ограничения по сравнению с нативным приложением: системные панели, уведомления и фоновые процессы контролируются iOS. Внешний вид статус-бара может немного отличаться в зависимости от версии iOS.
